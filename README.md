# 角色生理档案 · TauriTavern 移植版

把 Tavo 插件 **角色生理档案 / Character Physiology**（`com.taby.char-physiology` v3.0.32，原作者 **Taby / KeeK**）
移植成 **TauriTavern / SillyTavern** 的第三方扩展。

> ⚠️ **版权说明**：原插件没有公开的开源许可证，本仓库是个人移植，原作版权归原作者所有。
> 公开分发或二次发布前，建议先征得原作者 Taby / KeeK 同意。

## 安装

在 TauriTavern（或 SillyTavern）里：**扩展** → **安装扩展**，填入仓库地址：

```
https://github.com/asukapobyu-dot/tt-shengli
```

装好后刷新页面。TauriTavern 只接受 `http(s)` 的 Git 仓库地址，不支持压缩包安装，仓库需要是公开的。

## 入口

| 位置 | 内容 |
| --- | --- |
| 聊天页右侧悬浮按钮 | 打开 / 收起档案面板（可拖动） |
| 输入框左边的魔杖菜单 | 打开面板、打开设置、AI 扫描角色、重新扫描角色 |
| AI 最后一条消息的按钮栏（心跳图标） | 从此消息刷新生理档案 |
| 扩展页 →「角色生理档案」 | 启用、自动分析、AI 通道、注入、新角色默认周期 |

自定义 API 密钥、注入模板、角色名单等更细的设置在面板的「设置」页里。

## 与原插件的区别

- **年龄检测**：去掉了原版按描述关键词猜测年龄的功能（经常误判）。
  - 只有角色卡里**明确写出的年龄小于 18 岁**才不建档；没写年龄的按成年处理。
  - 卡上写明已满 18 岁、却被拦下的角色，可以在面板里点 **「确认成年」**，填入卡上的年龄后正常建档。
  - 旧版误判为未成年的角色会转为“未追踪”，可以重新确认。
  - 写明未满 18 岁的角色永远不会被卷入性内容。
- **注入方式**：不再新建世界书，改用酒馆的“扩展提示词”注入。
  - 只有模型看得到，不修改聊天记录。
  - 可选放在你最新一条消息之前或之后。
  - 后台生成（quiet）不注入。
- **AI 通道**：默认用酒馆当前的 API 和模型；也可以指定一个“连接配置”（Connection Manager），不影响主聊天。
  - 面板里填了自定义 API（OpenAI 兼容）时优先用它。遇到跨域限制会自动改走 TauriTavern 后端转发。
  - 密钥只放在单次请求里，不写进酒馆的密钥库。
  - 选中的连接配置不存在时会报错提示，不会悄悄换成别的模型。
- **数据存放**：
  - 每个聊天的档案存在该聊天的元数据里。
  - 全局设置存在酒馆的扩展设置里（settings.json）。
  - 角色图片存在用户文件目录（`/user/files/charphys-*`）。
- **界面**：
  - 原版侧栏按钮改为魔杖菜单项。
  - 确认对话框改用酒馆的弹窗。
  - 样式全部限定在面板内部，不影响酒馆和其他扩展。
  - 去掉了“从 Tavo 导入图片”（酒馆没有对应能力），保留“上传图片”。

## 更新记录

- **0.1.1**：修复初始化时卡上没写年龄的角色被判为未成年（显示 minor）。
  - 原因：初始化时 AI 会给每个角色填一个年龄，卡上没写时它会自己猜，猜出不到 18 岁就被拦下；一致性复核一步还会采纳 AI 的“幼态 / 未成年”标记。
  - 现在只认角色卡（和世界书）原文里写明的年龄，AI 猜的年龄不算；猜出来不到 18 岁的会被丢掉，档案里按“未写明”处理。
  - 之前被误拦的角色，更新后会自动变成“未追踪”，在角色名单里打开追踪后重新初始化即可。
- **0.1.0**：首个版本。

## 已知限制

- 未在全部机型上实测，手机竖屏布局如有遮挡请反馈。
- iOS 版 TauriTavern 不允许覆盖接口地址，自定义 API 遇到跨域时无法走后端转发，会直接报错。

## 开发

```bash
npm install --no-save linkedom   # 只有界面测试需要；没有时那两个测试自动跳过
node tests/run-all.mjs
```

| 文件 | 作用 |
| --- | --- |
| `index.js` | 入口：等酒馆就绪后启动；导出注入拦截器 `charPhysiologyInterceptor` |
| `src/engine.js`、`src/panel.js` | 原插件的引擎与面板（有移植补丁） |
| `src/tavo-shim.js` 及 `src/tt-*.js` | 把原插件用到的 Tavo 接口映射到酒馆（存储、聊天数据、AI、文件） |
| `src/runtime.js` | 监听酒馆事件，触发自动分析与注入 |
| `src/ui.js`、`src/settings.js` | 魔杖菜单、消息按钮、扩展设置区 |
| `src/legacy/` | 原插件的清单与入口代码（仅供对照，不会被加载） |
